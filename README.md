# JS FizzBuzz

Mini progetto in JavaScript che genera la sequenza FizzBuzz da 1 a 100 e la stampa in pagina in una lista HTML.

## Funzionalita
- Stampa "Fizz" per i multipli di 3
- Stampa "Buzz" per i multipli di 5
- Stampa "FizzBuzz" per i multipli di 3 e 5
- Stampa il numero negli altri casi
- Elementi visualizzati con classi Bootstrap per un feedback visivo

## Tecnologie
- HTML
- CSS
- JavaScript (vanilla)
- Bootstrap (via classi CSS)

## Struttura progetto
- `index.html`
- `css/`
- `js/script.js`

## Come usare
1. Apri `index.html` nel browser
2. La lista FizzBuzz viene generata automaticamente

## Note
Il contenuto e generato via DOM in `js/script.js`.
